# Реестр ресурсов и лицензий

## Внешние зависимости
**Нет.** Игра не подключает ни одной сторонней библиотеки, движка, шрифта, изображения или звукового файла.

| Что используется | Назначение | Лицензия |
|---|---|---|
| WebGL2 (API браузера) | графика | часть платформы браузера |
| WebAudio (API браузера) | звук | часть платформы браузера |
| Canvas 2D (API браузера) | процедурное рисование текстур в атлас, зарисовки, карта | часть платформы браузера |
| Системный шрифт Georgia / PT Serif / Times (CSS font stack) | текст интерфейса | шрифт системы пользователя, не распространяется с игрой |

Инструменты разработки (не входят в игру): Node.js, Playwright + Chromium (Apache-2.0) — только для автотестов и скриншотов.

## Референсы
Фото 1–5 из задания использованы только как ориентир настроения, композиции и архитектуры. Ни один пиксель референсов в игру не скопирован.
