# Beyond the Shadows — план проекта

## Цель
Полная сюжетная 2.5D-игра (фольклорный хоррор / детектив) по сценарию «Beyond the Shadows» на собственном фреймворке, с полной RU/EN локализацией, запускаемая по ссылке GitHub Pages.

## Анализ платформы и стек
* Целевая платформа — браузер (запуск по ссылке GitHub Pages, без установки). Это определило стек:
  * **WebGL2** — 3D-пространство, пиксельные текстуры, спрайты, тени, постобработка.
  * **WebAudio** — весь звук и музыка синтезируются в реальном времени.
  * **Чистый JavaScript (ES5/ES2015), без сборщика и без зависимостей.** Скрипты подключаются обычными `<script>`, поэтому игра работает и с GitHub Pages, и при открытии `index.html` с диска.
* Готовые движки и библиотеки не используются. Все текстуры, спрайты, портреты, иконки, музыка и звуки генерируются кодом → нет проблем с лицензиями ассетов.

## Этапы
| Этап | Содержание |
|---|---|
| A | Архитектура, стек, воспроизводимый запуск (`index.html`) |
| B | Фреймворк: цикл, рендерер, камера, сцены, ввод, коллизии, навигация, ресурсы |
| C | UI, диалоги, локализация, аудио, сохранения, NPC, журнал, инвентарь, карта |
| D | Все локации, персонажи, сюжет от пролога до эпилога |
| E | Музыка, SFX, погода, свет, тени, катсцены |
| F | Критики, прохождение на двух языках, исправления |
| G | Финальная документация и отчёт |

Текущий статус — в `IMPLEMENTATION_STATUS.md`.
