# Beyond the Shadows

*По ту сторону тени* — 2.5D фольклорный хоррор-детектив. Сербская деревня Паклештица, ярмарка, игра «Поймай тень» — и старуха, которая ест человеческие тени. Тринадцатилетний Джордже, который всё замечает, должен остановить её раньше, чем станет следующим.

Полная сюжетная игра: пролог, 11 глав и эпилог, русский и английский языки. Собственный движок на WebGL2 + WebAudio, без сторонних библиотек; вся графика, музыка и звуки генерируются кодом.

## Как запустить

### По ссылке (GitHub Pages)
1. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Выберите ветку (например, `main` после слияния или текущую ветку) и папку **`/ (root)`**, нажмите **Save**.
3. Через минуту игра доступна по адресу `https://<владелец>.github.io/<репозиторий>/` — для этого репозитория: `https://monskov1-gif.github.io/Beyond-the-Shadow/`.

Сборка не нужна: `index.html` в корне и есть игра. Файл `.nojekyll` отключает обработку Jekyll.

### Локально
Откройте `index.html` в браузере (двойной клик) или запустите любой статический сервер в корне: `npx http-server .`.

Нужен браузер с WebGL2: свежие Chrome, Edge, Firefox или Safari 15+. Работает с клавиатурой, геймпадом и на телефонах/планшетах (сенсорное управление).

### На телефоне и планшете
Откройте ту же ссылку в мобильном браузере и держите устройство горизонтально. На экране появятся:
* **джойстик** — коснитесь левой половины экрана и ведите пальцем; если отвести палец до края, Джордже побежит;
* **«Действие»** (большая кнопка справа) — поговорить, осмотреть, войти; подсказка над предметом тоже нажимается;
* **«Тень»** — внимательно смотреть на тень человека рядом; **«Бег»** — включить/выключить бег;
* сверху — **Журнал, Карта, Вещи, Пауза**. В диалогах коснитесь окна текста, чтобы продолжить, или выберите вариант ответа.

Интерфейс сам подстраивается под размер экрана; размер можно поменять в *Настройки → Размер интерфейса*. Сенсорные кнопки включаются автоматически на сенсорных устройствах (*Настройки → Сенсорное управление*: авто / вкл. / выкл.).

## Управление
| Действие | Клавиши | Геймпад |
|---|---|---|
| Ходьба | WASD / стрелки | левый стик / крестовина |
| Бег | Shift | бамперы / RT |
| Действие, далее в диалоге | E / Пробел / Enter | A |
| Смотреть на тень человека рядом (зарисовка) | F | X |
| Журнал | J | Y |
| Карта | M | Back |
| Вещи | I / Tab | LT |
| Пауза / назад | Esc | B / Start |

Клавиши можно переназначить: *Настройки → Управление*.

## Что внутри
* **Расследование:** журнал разделяет наблюдения, подтверждённые факты и гипотезы; записи можно связывать («Связать две записи»), из связей рождаются гипотезы и схема деревни с датами смертей и появлениями Яглики.
* **Тени:** у каждого персонажа своя тень, которая следует за светом — и может запаздывать, поворачиваться сама, отходить от ног, исчезать. Клавиша F — внимательно посмотреть и зарисовать.
* **Мир:** деревня из 36 домов, церковь с кладбищем, ярмарочная поляна со столбом, дом на холме, дом у леса, окрестности с рекой, мостом, мельницей и полями; 8 интерьеров. Время суток, туман, дождь, гроза с молниями, ветер, мокрые поверхности и лужи.
* **Звук:** генеративная музыка (балканский лад, 7/8 на ярмарке, хор в финале), окружение, позиционные эффекты, субтитры звуков.
* **Сохранения:** автосохранение после важных событий, 3 ручных слота.

## Для разработчиков
* `?dev=1` — счётчик FPS и времени кадра (или *Настройки → Режим разработчика*).
* Тестовые сцены: `?test=render`, `?test=collision`, `?test=audio`, `?test=loading`, `?test=view&loc=village&time=night&weather=rain&x=54&z=50`.
* Проверка локализации и данных: `node tools/validate.mjs`.
* Полное автопрохождение через реальные взаимодействия: `node tools/playthrough.mjs ru` / `en`.
