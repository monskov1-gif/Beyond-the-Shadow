# Beyond the Shadows — техническая архитектура

## Стек и обоснование
| Слой | Технология | Почему |
|---|---|---|
| Платформа | Браузер (Chrome/Edge/Firefox/Safari с WebGL2) | Запуск по ссылке GitHub Pages без установки |
| Графика | **WebGL2** (низкоуровневый API браузера) | 3D + спрайты + постобработка |
| Звук | **WebAudio** (API браузера) | Синтез музыки и всех эффектов в реальном времени |
| Язык | JavaScript (ES5+), без сборщика | Обычные `<script>` → работает и с `file://`, и на Pages |
| Сторонние библиотеки | **нет** | Фреймворк написан с нуля |

Сборка не нужна: исходники и есть релиз. Инструменты в `tools/` (Node + Playwright, установлены в окружении разработки) нужны только для тестов и скриншотов.

## Модули фреймворка (`src/`, пространство имён `BTS`)
| Система ТЗ | Файлы | Что делает |
|---|---|---|
| Core/Application | `core/core.js`, `core/app.js` | Логирование, конфиг/настройки (localStorage), события, математика (mat4, шум), детерминированный RNG; главный цикл с ограничением delta time, обработка ошибок (экран ошибки), dev-оверлей FPS/время кадра |
| Input | `core/input.js` | Клавиатура/мышь/геймпад → действия; переназначение клавиш |
| Renderer | `gfx/gl.js`, `gfx/renderer.js`, `gfx/shaders.js`, `gfx/camera.js`, `gfx/mesh.js` | Карта теней солнца/луны, HDR-сцена в низком разрешении (единый pixel scale), освещение до 16 точечных источников с мерцанием, материалы (камень, дерево, ткань, металл, стекло, мокрая земля, вода, листва), лужи и мокрые поверхности, туман, bloom, глубина резкости (tilt-shift), цветокоррекция, виньетка, сепия, вспышки молний, nearest-апскейл |
| Asset pipeline | `gfx/atlas.js`, `gfx/textures.js`, `gfx/sprites_chars.js`, `gfx/sprites_props.js`, `ui/portraits.js` | Все текстуры, спрайты (19 персонажей × 13 анимаций × 4 направления), портреты с 8 эмоциями, иконки — рисуются кодом в атлас 2048² при запуске |
| Scene/World | `world/world.js`, `world/builder.js`, `locations/*.js` | Загрузка/выгрузка локаций (статика кэшируется), точки появления, переходы, триггеры, интерактивные объекты, затухание домов, закрывающих игрока |
| Entity/Component | `world/entity.js` | Entity + компоненты Animator, ShadowCaster, Brain, движение по пути |
| Collision/Navigation | `world/physics.js` | Круг против AABB/кругов, выталкивание, сетка навигации + A* со сглаживанием пути |
| Animation | `world/entity.js` (Animator) | Кадровые клипы `<anim>_<dir>`, события кадров (шаги) |
| Lighting/Shadow | `world/env.js`, `world/shadows.js` | Время суток (утро/день/вечер/ночь), 6 типов погоды с плавными переходами, ветер, молнии, влажность; собственная система теней персонажей (запаздывание, вытягивание, поворот, отделение, исчезновение, «звериная» тень на земле и стенах) |
| Частицы | `world/particles.js` | Дождь с брызгами, капли с крыш, дым, искры, светлячки, пыль в лучах, листья, лепестки, «тёмные клочья» |
| NPC | `world/npc.js`, `data/npcs.js` | Явный автомат состояний (idle, walking, talking, working, frightened, suspicious, mourning, dead), расписания по сюжету и времени суток, рассинхронизация |
| Audio Engine | `audio/audio.js`, `audio/sfx.js`, `audio/ambience.js`, `audio/music.js` | Шины music/ambience/sfx/ui/voice, лимитер, реверберация, позиционный звук, приглушение под диалогом, лимиты голосов; 60+ синтезированных SFX; слои окружения; 13 музыкальных состояний с кроссфейдом |
| UI | `ui/ui.js`, `ui/screens.js`, `ui/journal.js`, `ui/mapinv.js`, `css/ui.css` | Стек экранов с навигацией клавиатурой/геймпадом/мышью, HUD, диалоговое окно с портретами, журнал (наблюдения/факты/гипотезы/зарисовки/задачи + связывание), карта, инвентарь, настройки, сохранения, титры, субтитры звуков |
| Quest/Data | `game/story.js`, `game/dialogue.js`, `game/cutscene.js`, `game/state.js`, `story/*.js`, `data/*.js` | Сюжетные шаги (beats) по главам, флаги, условия, улики, последствия выборов, катсцены на async-скриптах |
| Localization | `game/i18n.js`, `locale/*.js` | RU/EN словари отдельно от логики, стабильные ключи, форматирование `{param}`, проверка отсутствующих/пустых/лишних ключей, смена языка на лету |
| Save/Load | `game/save.js` | 3 слота + автосохранение, версия формата, контрольная сумма, миграция, запрет сохранения в критических сценах |
| Dev | `game/devtools.js`, `locations/testscenes.js` | Режим разработчика, тестовые сцены (`?test=render|collision|audio|loading|view`), API автопрохождения |

## Порядок кадра
`Input.update → UI (меню/диалог) → Cutscene timers → World.update (игрок, NPC, коллизии, триггеры, фокус взаимодействия, затухание) → Story.update → Env.update → Camera.update → Particles → Ambience → Render (тени → сцена → спрайты → тени персонажей/частицы → bloom/DOF → композит)`.

## Данные сюжета
* `story/*.js` — сюжетные шаги: время/погода/настроение, цель, расстановка NPC, интерактивы, триггеры, катсцены.
* Диалоги — массивы шагов: `['speaker','key']`, мысли `'>'`, описания `'*'`, паузы `'~'`, выборы, условия, эффекты, метки/переходы. Текст — только в `locale/`.
* Защита: лимит шагов диалога (защита от бесконечных циклов), проверка меток, `tools/validate.mjs` проверяет все ссылки.

## Запуск
Открыть `index.html` (локально или по ссылке GitHub Pages). Параметры для разработки: `?dev=1` (FPS), `?test=view&loc=village&time=night&weather=rain`.
